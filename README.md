## Usage
Simply go to [ggst.danew9c.com](https://ggst.danew9c.com) to check it out. <br>
- Use `ggst.danew9c.com/api/player?name={your_name}` to get your profile
- Use `<img src="https://ggst.danew9c.com/api/player?name={your_name}" alt="ggst_profile">` on your website
- Use `![ggst_profile](https://ggst.danew9c.com/api/player?name={your_name})` on github (cause why not)

## Running Locally
```sh
git clone https://github.com/New9c/ggst_profile
cd ggst_profile
node server.js
```
