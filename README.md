# GGST Profile

![ggst_profile](https://ggst.danew9c.com/DaNew9c)

A simple profile to show off your rank in strive.

This is possible thanks to [puddle farm](https://puddle.farm) and it's API.

## Usage
Simply go to [ggst.danew9c.com](https://ggst.danew9c.com) to check it out. <br>
- Use `ggst.danew9c.com/{your_name}` to get your profile
- Use `<img src="https://ggst.danew9c.com/{your_name}" alt="ggst_profile">` on your website
- Use `![ggst_profile](https://ggst.danew9c.com/{your_name})` on github (cause why not)
